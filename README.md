# Fitness_dashboard
Fitness App Dashboard – A sleek BI dashboard tracking user health metrics: Avg HealthScore (89.74), Steps (8.72K), Calories Burned (2.24K), and 365 total sessions. Includes a user profile with heart rate &amp; sleep stats, plus a monthly HealthScore trend chart. Built for fitness apps needing clean, data-driven wellness insights.
